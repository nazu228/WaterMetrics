# 🚀 Руководство по развертыванию обновлений и лицензий в Яндекс Облаке

Данная система обеспечивает защищенную удаленную доставку обновлений для **WaterMetrics** на серверах в РФ без необходимости арендовать и обслуживать постоянный VPS.

---

## 📁 Структура решения

* `tools/package_release.py` — консольная утилита для сборки релизных архивов и генерации `version.json` с SHA-256 хэшами.
* `services/updater_service.py` — клиентский модуль обновления с проверкой целостности SHA-256, поддержкой S3/Serverless и fallback на GitHub.
* `serverless/yandex_cloud_function.py` — бессерверный обработчик для валидации лицензий и выдачи временных ссылок (Pre-Signed URLs).
* `config.py` — URL манифеста и настройки сервера.

---

## 🛠️ Шаг 1. Создание бакета в Яндекс Облаке (Object Storage)

1. Войдите в консоль [Яндекс Облака](https://console.yandex.cloud/).
2. Перейдите в **Object Storage** ➔ **Создать бакет**:
   * **Имя бакета**: `watermetrics-releases` (или ваше уникальное имя).
   * **Максимальный размер**: без ограничений.
   * **Доступ к чтению объектов**: *Публичный* (на первом этапе) или *Ограниченный* (когда включите лицензии).
3. Нажмите **Создать бакет**.

---

## 📦 Шаг 2. Сборка и загрузка релиза

1. Запустите в терминале проекта сборщик:
   ```bash
   python tools/package_release.py --bucket watermetrics-releases
   ```
2. Скрипт создаст папку `dist_release/` с двумя файлами:
   * `watermetrics-v1.3.0.zip` (компактный архив с исходным кодом/ресурсами)
   * `version.json` (манифест с описанием, версией и SHA-256 хэшем)
3. Загрузите оба файла в созданный бакет `watermetrics-releases` через веб-интерфейс консоли Яндекса.

---

## 🔐 Шаг 3. Включение защиты и лицензий (в будущем)

Когда потребуется закрыть прямой доступ к файлам и выдавать обновления только по лицензионным ключам:

1. Перейдите в **Cloud Functions** ➔ **Создать функцию**.
2. Имя функции: `watermetrics-license-checker`.
3. Среда выполнения: `Python 3.11` или `Python 3.12`.
4. Вставьте код из `serverless/yandex_cloud_function.py`.
5. В блоке **Переменные окружения** укажите:
   * `S3_BUCKET_NAME`: `watermetrics-releases`
   * `AWS_ACCESS_KEY_ID`: Ключ сервисного аккаунта с ролью `storage.viewer`
   * `AWS_SECRET_ACCESS_KEY`: Секретный ключ сервисного аккаунта
6. Сделайте функцию публичной (включите флаг **Публичная функция**).
7. Полученный URL функции вставьте в `config.py` в переменную `UPDATE_MANIFEST_URL`.

---

## 🛡️ Безопасность

* **Контрольные суммы**: Перед установкой скачанный файл сверяется по алгоритму SHA-256. Любая попытка подмены или повреждение файла при скачивании будут немедленно заблокированы.
* **HWID**: Приложение автоматически вычисляет стабильный хэш конфигурации компьютера Windows (`services.updater_service.get_system_hwid()`) для привязки ключа к одному ПК.
* **Crash-Guard**: Если после обновления программа упадет при первом запуске, встроенный сторожевой механизм автоматически откатит приложение на предыдущую работоспособную версию.
