# 📝 WaterMetrics — Журнал изменений и патч-лог

Все заметные изменения, исправления ошибок и новые функции проекта документируются в этом файле.

## 🚀 [v1.1.0] — 2026-08-25 (Текущая версия)

### 🛡️ Стабильность, многопоточность и управление окном (UI/UX & Core Fixes)
- **Защита от гонки потоков расчета (Ctrl+R / F5)**: Добавлена блокировка повторного создания воркера `CalculationWorker` во время выполнения расчетов. При попытке повторного вызова пользователю выводится информационный тост.
- **Поддержка сворачивания и интеграция с Windows Taskbar**: Добавлены системные флаги `WS_MINIMIZEBOX` и `WS_SYSMENU` для безрамочного окна (`FramelessWindowHint`), что обеспечивает корректное сворачивание/восстановление по клику на иконку в Панели задач Windows и через кнопку «Свернуть».
- **Разворачивание / восстановление окна по двойному клику**: Реализован обработчик `mouseDoubleClickEvent` для кастомного заголовка `CustomTitleBar`.
- **Изменение размеров безрамочного окна (QSizeGrip)**: Интегрирован виджет изменения размеров окна в правый нижний угол статус-бара с автоматическим скрытием в полноэкранном режиме.
- **Умная вставка ячеек из Excel**: Устранен конфликт фокуса и выделения при множественной вставке (Ctrl+V) — фокус и выделение теперь устанавливаются строго на последнее заполненное поле.
- **Очистка терминала системных логов**: Метод `_clear_logs` теперь полностью очищает консоль логов и выводит статусное сообщение через всплывающий тост без засорения истории.
- **Устранение дублирования уведомлений**: Исправлен двойной вызов всплывающего тоста при ошибках генерации отчетов.
- **Защита от утечки колбэков в ThemeManager**: Автоматическая фильтрация и удаление ссылок на уничтоженные C++ объекты Qt при смене темы оформления.
- **Исправление путей ассетов**: Скорректирована глубина поиска ресурсов в окне «О программе» для 100% надежного нахождения файлов.
