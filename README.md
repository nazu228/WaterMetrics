# 💧 WaterMetrics Professional Edition

Система автоматизированного расчета, балансировки и генерации отчетности по водопотреблению многоквартирных домов (МКД).

---

## 🚀 Основные возможности
- **Двухфазный расчет и распределение**: автоматический перенос показаний со сдвигом расчетного периода, синхронное начисление нормативов на пустые квартиры и сведение сумм с точностью $< 0.0005\text{ м}^3$.
- **Мастер замен ИПУ**: фиксация снятых и вновь установленных приборов учета.
- **Премиальный интерфейс**: дизайн в стиле Apple Frosted Glass, интерактивный конструктор дашборда и настраиваемые 3D-волны заднего плана на OpenGL.
- **Мастер первой проводки (Onboarding)**: интерактивный пошаговый гид со встроенными демо-данными.
- **Автоматические удаленные обновления**: проверка новых версий и скачивание релизов напрямую через **GitHub Releases**.

---

## 🛠️ Установка и запуск

### 1. Требования
- Python 3.10+
- ОС: Windows 10/11

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python main.py
```

---

## 📦 Сборка исполняемого файла (.exe)
```bash
pyinstaller WaterMetrics.spec
```
Итоговый файл будет создан в папке `dist/WaterMetrics.exe`.

---

## 🏷️ Публикация обновлений через GitHub
Приложение настроено на автоматические обновления через **GitHub Releases**.
Чтобы выпустить новую версию:
1. Создайте и отправьте новый Git-тег:
   ```bash
   git tag v2.6.0
   git push origin v2.6.0
   ```
2. **GitHub Actions** автоматически соберет `WaterMetrics.exe` и прикрепит его к релизу.
3. Все пользователи приложения получат всплывающее уведомление и смогут обновиться в 1 клик!
